# DYNAMIC PRODUCT PAGE + CATEGORY MANAGEMENT

## COMPLETE REPLIT IMPLEMENTATION SPECIFICATION

## 1. OBJECTIVE

Create a fully dynamic Product Management and Product Page system for the website.

The system must have:

1. Category Management
2. Product Management
3. Dynamic Product Page
4. Dynamic Header
5. Dynamic Technical Database
6. Dynamic Product Left Section
7. Dynamic Product Right Section
8. Dynamic Typical Applications section
9. Dynamic Related Products
10. Dynamic Features
11. Dynamic Images/Gallery
12. Dynamic Videos
13. Dynamic FAQ
14. Dynamic SEO
15. Publish / Unpublish
16. Product Preview
17. Mobile Responsive Design

IMPORTANT:

DO NOT create separate hard-coded pages for individual products.

Every product page must be generated from database data.

==================================================
2. REMOVE PREVIOUS PRODUCT PAGE IMPLEMENTATION
==============================================

Before implementation:

* Audit the existing Product Page code.
* Identify all hard-coded product names, descriptions, prices, images and specifications.
* Remove the old hard-coded product-page rendering logic.
* Do not duplicate old and new Product Page systems.
* Keep existing website authentication and common layout where compatible.
* Replace only the Product/Category architecture with the new dynamic system.
* Existing URLs should continue working where possible.

The final system must have ONE dynamic Product Page engine.

==================================================
42. ERROR HANDLING
==================

If product does not exist:

Show proper 404 Product Not Found page.

If product is unpublished:

Do not display publicly.

If related product was deleted:

Automatically remove or ignore invalid relationship.

If image is missing:

Show a safe fallback image.

If optional section has no content:

Do not render an empty section.
